# Happy Birthday, Retshego! ✿

A responsive, interactive sweet-sixteen birthday website for Retshego.

## Features
- Cream, pink and baby-blue palette using the 60/30/10 design rule.
- Custom CSS birthday-cake illustration.
- Interactive cupcake-decorating steps.
- Mini soccer penalty shootout with a live score.
- Random concert introductions and optional sound effects.
- Animated birthday letter reveal.
- Mobile layout, keyboard focus styles and reduced-motion support.

## Run locally
Open index.html in a browser. No build step or dependencies required.

## Publish
The site is configured for GitHub Pages from the main branch and repository root.
